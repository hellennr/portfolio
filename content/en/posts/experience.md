### Hyper Tensão Project – Educational Game

Development of an educational game to raise awareness about hypertension.

- Use of programming logic and OOP concepts
- Pygame library

### Minesweeper – C Game  

Implementation of the Minesweeper game using C, with logic to place mines, navigate the board, and detect when the player wins or loses.

- Use of arrays, loops, conditionals, and user input  

### Battleship – C Game with Local Network  

Implementation of the Battleship game for two players over a local network (TCP/IP).

- Use of threads for parallelism  
- Complete game logic: ship placement, turn alternation, hit/miss detection  
- Practical application of thread synchronization, control flow, and data structures (arrays and matrices)
