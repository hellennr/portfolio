### Projeto Hyper Tensão – Jogo Educacional

Desenvolvimento de jogo educativo para conscientização sobre hipertensão

- Uso de lógica de programação e conceitos de POO
- Biblioteca Pygame

### Campo Minado – Jogo em C  

Implementação do jogo Campo Minado usando C, com lógica para posicionar minas, navegar no tabuleiro e detectar quando o jogador perde ou ganha.
 
- Utilização de matrizes, loops, condicionais e entrada de dados pelo usuário.  

### Batalha Naval – Jogo em C com Rede Local  

Implementação do jogo Batalha Naval para dois jogadores via rede local (TCP/IP).  

- Uso de threads para paralelismo
- Lógica completa do jogo: posicionamento de navios, alternância de turnos, detecção de acertos e derrotas.  
- Aplicação prática de sincronização de threads, controle de fluxo e estruturas de dados (matrizes e arrays).
